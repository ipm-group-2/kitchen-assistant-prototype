# Sous-Chef Ratchet — Stage 4 Functional Prototype

A responsive, high-fidelity interaction prototype for NOVA FCT's Human-Computer Interaction course (2026/27).

## Run locally

No installation or backend is required. Open `index.html` in a modern browser, or serve the folder with any static web server.

## Evaluated scenarios

1. Add milk to the inventory using barcode scanning or manual entry.
2. Find a suitable recipe using available and expiring ingredients, then verify ingredient availability before cooking.
3. Follow the complete Ratatouille cooking flow using step navigation, voice controls and an automatic parallel timer.

## Prototype boundaries

- Ratatouille is the only recipe with a complete guided cooking flow.
- Barcode scanning is simulated.
- The step videos are interaction demonstrations rather than production cooking footage.
- Data is stored only for the current browser session and resets on refresh.
- Shopping is included as a supporting feature but is not one of the three evaluated flows.

## Technology

Plain HTML, CSS and JavaScript. No framework, build step, account or backend is required.

## Deployment

The repository is designed for GitHub Pages and uses only static files.
